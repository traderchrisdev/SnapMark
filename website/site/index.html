A free plugin for Supernote

Turn anything on your screen into a note you can write on.

Tap the floating button in any app, drag a box over the part you want, and you're writing on it a second later. In PDFs and EPUBs your handwriting comes along as real ink, with a link back to the page.

Free · Open source (MIT) · No internet access · Tested on Manta

01 How it works

  1. Read and mark up

    A book, a PDF, Kindle, a web page. Anything on your Supernote.

  2. Tap, drag a box

    The floating button captures the screen. Keep the whole thing or just the part you want.

  3. Write on it

    A new note opens with your cut-out at the top and the rest of the page free to write on.

02 What it does

Floating capture button

Floats over every app, about 5 mm across. Tap it to capture; drag it out of the way. It stays where you leave it.

Snap region

Box a paragraph, a verse or a chart. Just that part goes at the top of a fresh page, enlarged if it's small.

Your ink stays ink

Snap a PDF or EPUB page and your handwriting comes along as real strokes you can still erase and move, on any page, landscape pages included. Marker highlights become clean underlines, right under the line you marked.

A link back

Every snap from a document carries a ↩ Book, p. 42 link, placed where it doesn't cover your text. One tap and you're back where you were reading.

Into the note you're writing

Reading a PDF next to your own notes? A region snap can go straight onto your current page, below what's there, with your handwriting as real ink and a link back to the PDF page.

Inbox, margins, screenshots

Collect every snap in one notebook, leave a writing margin, turn a Supernote screenshot into a note, or export a page as PNG.

03 Install

  1. Download the .snplg file from the latest release.
  2. Copy it into the MyStyle folder on your Supernote, by USB or with the Supernote Partner app.
  3. On the device: Settings → Apps → Plugins → Choose Installation Package, then pick the file.

Needs firmware with plugin support: Chauvet 3.29.43 or later on Manta and Nomad, 2.26.40 or later on A5 X and A6 X. If SnapMark says it “is not compatible with the current system version”, please report it with your model and firmware. Updating? Install over the old version, then restart your Supernote. The how-to guide covers every feature and setting.

04 FAQ

Which Supernote models does it work on?

It's tested on the Manta, and a Nomad user has been using it and reporting back. It's written to work on the A5 X and A6 X too, but those are untested so far. If you try one, please report how it went on GitHub.

It says “not compatible with the current system version”.

Update to SnapMark 0.13.0 or later. Version 0.12.0 was built with Supernote's newest plugin library, which some firmware refuses (a Nomad on Chauvet 3.29.45 beta did). 0.13.0 uses the older library that every firmware with plugin support accepts. If it still happens, please report it with your model and firmware version.

Can I paste a snap into a note I'm already writing?

Yes. In SnapMark's settings, set Where snaps go to Into the note I'm working in. Open your note, go to the PDF and use Snap region (or the floating button): the cut-out lands on your current page below what's there, as a picture you can move with the lasso, with a link back to the PDF page. From a PDF, your handwriting inside the box comes along as real ink you can still erase.

Does it send anything anywhere?

No. SnapMark asks only for file access and has no internet access. Your snaps are ordinary notes on your device.

Why doesn't it ask permission to capture the screen?

The floating button is native code running inside Supernote's plugin system, which is already allowed to draw over apps and read the screen. SnapMark only captures when you tap the button, and the source code is open if you want to check.

Tapping the button with my pen left a dot on my page.

The Supernote pen writes through anything floating over a page. Keep the button on the file name at the bottom right of a note, where the pen doesn't write, or tap it with your finger.

Where are my snaps saved?

In Note/Snaps/: page snaps in a folder per book, captures in Snaps/Screenshots/, and the optional inbox at Snaps/Snaps inbox.note. With Into the note I'm working in, region snaps go into your own note instead. You can change the folder in SnapMark's settings.

How do I update?

Install the new .snplg over the old one, then restart your Supernote so the new version is the one running. Your settings are kept.

How do I uninstall it?

Turn the floating button off in SnapMark's settings, then remove SnapMark in Settings → Apps → Plugins. Your snaps stay where they are.

Does this website track me?

Only if you allow it. If you accept the cookie question, the site uses Google Analytics to count visits and download clicks. If you decline, nothing is loaded. You can change your choice under "Cookie settings" at the bottom of the page. The plugin itself never sends anything.

Is it an official Supernote app?

No. SnapMark is an independent, open-source project. It isn't affiliated with or endorsed by Ratta or Supernote.

Something doesn't work.

Please open an issue on GitHub with your device, firmware version, SnapMark version and what you tapped. In SnapMark's settings, Problem report → Save a log file puts a log in EXPORT/ you can attach (check it first: it may contain note names). The troubleshooting table may already have the answer.
